# Пункт 21. Внутренняя энергия и энтропия газа Ван-дер-Ваальса. Равновесное и неравновесное расширение газа Ван-дер-Ваальса в теплоизолированном сосуде

### Внутренняя энергия и энтропия газа Ван-дер-Ваальса

> [!error] **Внутренняя энергия газа Ван-дер-Ваальса**
> Для 1 моля газа Ван-дер-Ваальса:
> $$U = c_V T - \frac{a}{V} + U_0.$$
> Для $\nu$ молей газа:
> $$U = \nu c_V T - \frac{\nu^2 a}{V} + U_0.$$

**Вывод:**
$\square$
1. Из термодинамического соотношения:
   $$\left(\frac{\partial U}{\partial V}\right)_T = T \left(\frac{\partial P}{\partial T}\right)_V - P.$$
2. Из уравнения Ван-дер-Ваальса $P = \frac{R T}{V - b} - \frac{a}{V^2} \implies \left(\frac{\partial P}{\partial T}\right)_V = \frac{R}{V - b}$.
3. Подставляя:
   $$\left(\frac{\partial U}{\partial V}\right)_T = T \frac{R}{V - b} - \left(\frac{R T}{V - b} - \frac{a}{V^2}\right) = \frac{a}{V^2}.$$
4. Интегрируя по $T$ и $V$:
   $$dU = c_V dT + \frac{a}{V^2} dV \implies U(T, V) = c_V T - \frac{a}{V} + U_0. \blacksquare$$

> [!error] **Энтропия газа Ван-дер-Ваальса**
> Для 1 моля газа:
> $$S = c_V \ln T + R \ln(V - b) + S_0.$$

**Вывод:**
$\square$
$$dS = \frac{dU + P dV}{T} = \frac{c_V dT + \frac{a}{V^2} dV + \left(\frac{RT}{V - b} - \frac{a}{V^2}\right) dV}{T} = c_V \frac{dT}{T} + R \frac{dV}{V - b}.$$
Интегрируя, получаем $S(T, V)$. $\blacksquare$

### Равновесное и неравновесное расширение газа Ван-дер-Ваальса в теплоизолированном сосуде

> [!note] **1. Равновесное (адиабатическое) расширение**
> В квазистатическом адиабатическом процессе $dS = 0$:
> $$c_V \frac{dT}{T} + R \frac{dV}{V - b} = 0 \implies T (V - b)^{R / c_V} = \text{const} \quad \iff \quad T (V - b)^{\gamma - 1} = \text{const}.$$
> При расширении ($V_2 > V_1$) температура газа понижается за счёт совершения внешней работы.

> [!note] **2. Неравновесное расширение в пустоту (опыт Джоуля)**
> При расширении в теплоизолированный вакуумированный сосуд:
> * Внешняя работа $A = 0$, теплообмен $Q = 0 \implies \Delta U = 0 \implies U_1 = U_2$.
> * Для 1 моля газа Ван-дер-Ваальса:
>   $$c_V T_1 - \frac{a}{V_1} = c_V T_2 - \frac{a}{V_2} \implies \Delta T = T_2 - T_1 = -\frac{a}{c_V} \left( \frac{1}{V_1} - \frac{1}{V_2} \right) < 0.$$
> * Поскольку $V_2 > V_1$, то $\Delta T < 0$ — **газ Ван-дер-Ваальса при расширении в вакуум охлаждается**!
> *Причина:* при увеличении объёма молекулы удаляются друг от друга, преодолевая силы межмолекулярного притяжения и затрачивая часть своей тепловой кинетической энергии.
