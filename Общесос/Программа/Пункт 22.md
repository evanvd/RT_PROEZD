# Пункт 22. Эффект Джоуля—Томсона. Дифференциальный и интегральный эффект Джоуля–Томсона для газа Ван-дер-Ваальса, температура инверсии

### Эффект Джоуля—Томсона

> [!info] **Определение 22.1** (Эффект Джоуля — Томсона)
> Стационарное адиабатическое протекание газа через дроссель (пористую перегородку) из области высокого давления $P_1$ в область низкого давления $P_2 < P_1$.
> Процесс является **изоэнтальпийным**:
> $$H_1 = H_2 \quad \iff \quad U_1 + P_1 V_1 = U_2 + P_2 V_2.$$

**Доказательство:**
$\square$
Внешняя работа сил давления: $A^* = P_1 V_1 - P_2 V_2$.
В адиабатических условиях ($Q = 0$): $\Delta U = U_2 - U_1 = A^* = P_1 V_1 - P_2 V_2 \implies U_1 + P_1 V_1 = U_2 + P_2 V_2 \implies H_1 = H_2. \blacksquare$

### Дифференциальный и интегральный эффект Джоуля–Томсона для газа Ван-дер-Ваальса, температура инверсии

> [!info] **Определение 22.2** (Дифференциальный и интегральный эффекты)
> * **Дифференциальный коэффициент:**
>   $$\mu_{\text{ДТ}} = \left(\frac{\partial T}{\partial P}\right)_H = \frac{T \left(\frac{\partial V}{\partial T}\right)_P - V}{C_P}.$$
> * **Интегральный эффект:**
>   $$\Delta T = T_2 - T_1 = \int_{P_1}^{P_2} \mu_{\text{ДТ}} dP.$$

> [!error] **Эффект для газа Ван-дер-Ваальса**
> Для 1 моля газа Ван-дер-Ваальса:
> $$\mu_{\text{ДТ}} \approx \frac{1}{c_P} \left( \frac{2a}{R T} - b \right).$$
> 
> * **Положительный эффект ($\mu_{\text{ДТ}} > 0$):** при $T < T_{\text{инв}}$ газ при дросселировании ($dP < 0$) **охлаждается** ($dT < 0$).
> * **Отрицательный эффект ($\mu_{\text{ДТ}} < 0$):** при $T > T_{\text{инв}}$ газ при дросселировании **нагревается** ($dT > 0$).
> 
> **Температура инверсии:**
> $$T_{\text{инв}} = \frac{2a}{R b} = \frac{27}{4} T_{\text{кр}} = 6{,}75 \, T_{\text{кр}}.$$
