# Пункт 22. Эффект Джоуля—Томсона. Дифференциальный эффект Джоуля–Томсона для газа Ван-дер-Ваальса, температура инверсии.

### Эффект Джоуля—Томсона

Эффектом Джоуля–Томсона называется изменение температуры газа при его адиабатическом дросселировании. Процесс дросселирования — это медленное протекание газа через препятствие (дроссель) под воздействием постоянного перепада давления. Дросселем может служить пористая перегородка, узкая трубка или приоткрытый вентиль. Процесс происходит без теплообмена с окружающей средой ($Q = 0$).

> **Рис. 7.6**

Рассмотрим процесс дросселирования газа из области с постоянным давлением $P_1$ в область с постоянным давлением $P_2$ ($P_1 > P_2$). Работа внешних сил над газом при вытеснении его из первой области равна $P_1 V_1$, а работа самого газа во второй области равна $P_2 V_2$. По первому началу термодинамики при $Q = 0$:
$$U_2 - U_1 = P_1 V_1 - P_2 V_2 \Longrightarrow U_1 + P_1 V_1 = U_2 + P_2 V_2.$$

Учитывая определение энтальпии $I = U + PV$, получаем:
$$I_1 = I_2. \tag{7.23}$$

Таким образом, процесс дросселирования происходит при постоянстве энтальпии (является изоэнтальпийным).

Характеристикой дифференциального эффекта (при малом перепаде давления $dP$) служит коэффициент Джоуля–Томсона:
$$\mu = \left(\frac{\partial T}{\partial P}\right)_I. \tag{7.24}$$

Поскольку $dI = C_P dT + \left[ V - T\left(\frac{\partial V}{\partial T}\right)_P \right] dP = 0$, получаем:
$$\mu = \left(\frac{\partial T}{\partial P}\right)_I = \frac{T\left(\frac{\partial V}{\partial T}\right)_P - V}{C_P}. \tag{7.25}$$

Для идеального газа $V = RT/P$, поэтому $\left(\frac{\partial V}{\partial T}\right)_P = V/T$, откуда $\mu = 0$. Температура идеального газа при дросселировании не изменяется.

Для газа Ван-дер-Ваальса подставим в (7.25) значение производной $\left(\frac{\partial V}{\partial T}\right)_P$ из (7.28). В приближении не очень плотного газа (пренебрегая членами второго порядка по поправкам $a$ и $b$):
$$\mu \approx \frac{\frac{2a}{RT} - b}{C_P}. \tag{7.26}$$

Из выражения (7.26) следует, что знак эффекта зависит от соотношения между силами притяжения (поправка $a$) и силами отталкивания (поправка $b$):
* Если преобладают силы притяжения ($\frac{2a}{RT} > b$), то $\mu > 0$, и газ при дросселировании охлаждается ($dT < 0$ при $dP < 0$). * Если преобладают силы отталкивания ($\frac{2a}{RT} < b$), то $\mu < 0$, и газ нагревается ($dT > 0$ при $dP < 0$).

Температура, при которой коэффициент Джоуля–Томсона меняет знак ($\mu = 0$), называется *температурой инверсии* $T_{\text{инв}}$:
$$T_{\text{инв}} = \frac{2a}{Rb}. \tag{7.27}$$

Сравнивая с критической температурой (7.18), находим связь для газа Ван-дер-Ваальса:
$$T_{\text{инв}} = \frac{27}{4} T_{\text{к}} = 6,75 T_{\text{к}}. \tag{7.28}$$

### Дифференциальный и интегральный эффект Джоуля–Томсона для газа Ван-дер-Ваальса, температура инверсии

Если перепад давления на дросселе велик, то происходит конечное изменение температуры газа $\Delta T = T_2 - T_1$. Этот эффект называется интегральным эффектом Джоуля–Томсона и вычисляется интегрированием дифференциального эффекта:
$$\Delta T = T_2 - T_1 = \int_{P_1}^{P_2} \left(\frac{\partial T}{\partial P}\right)_I dP = \int_{P_1}^{P_2} \frac{T\left(\frac{\partial V}{\partial T}\right)_P - V}{C_P} dP. \tag{7.29}$$

Если в начальном состоянии 1 газ Ван-дер-Ваальса находится под высоким давлением, а в конечном состоянии 2 расширяется до давлений порядка атмосферного (где его можно считать идеальным), то уравнение сохранения энтальпии $I_1 = I_2$ запишется как:
$$C_V T_1 - \frac{a}{V_1} + P_1 V_1 = (C_V + R) T_2.$$

Подставляя значение $P_1$ из уравнения Ван-дер-Ваальса (7.3), после простых преобразований получаем:
$$\Delta T = T_2 - T_1 = \frac{1}{C_P} \left( \frac{RT_1 b}{V_1 - b} - \frac{2a}{V_1} \right). \tag{7.30}$$

> ![Рис. 7.7. Кривая инверсии интегрального эффекта Джоуля–Томсона в приведенных координатах]
> **Рис. 7.7**

Условие инверсии интегрального эффекта ($\Delta T = 0$) дает связь температуры инверсии с начальным объемом:
$$T_{\text{инв}} = \frac{2a}{Rb} \frac{V_1 - b}{V_1}. \tag{7.31}$$

Переходя к приведенным параметрам, получаем уравнение кривой инверсии на координатной плоскости $(\pi, \tau)$:
$$\pi = 24\sqrt{3\tau} - 12\tau - 27. \tag{7.32}$$

График этой зависимости представлен на рис. 7.7. Область, ограниченная кривой инверсии, соответствует области охлаждения газа при дросселировании ($\Delta T < 0$).

Поскольку при дросселировании в области под кривой инверсии газы охлаждаются, этот процесс широко используется в технике для сжижения газов и получения сверхнизких температур. Однако для газов с очень низкой температурой инверсии (например, для водорода $T_{\text{инв}} \approx 216\text{ K}$, для гелия $T_{\text{инв}} \approx 23,8\text{ K}$) дросселирование при комнатной температуре приводит к их нагреванию. Поэтому перед дросселированием эти газы необходимо предварительно охладить ниже их температуры инверсии с помощью других хладагентов (например, жидкого азота).

Более эффективным методом охлаждения является обратимое адиабатическое расширение газа с совершением внешней работы в специальных машинах — *детандерах* (поршневых или турбодетандерах, разработанных П. Л. Капицей). В этом случае изменение температуры всегда отрицательно:
$$\left(\frac{\partial T}{\partial P}\right)_S = \frac{T}{C_P} \left(\frac{\partial V}{\partial T}\right)_P > 0,$$
и охлаждение происходит при любых начальных температурах без ограничений, накладываемых условиями инверсии.
