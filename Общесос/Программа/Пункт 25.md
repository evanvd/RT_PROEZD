# Пункт 25. Распределение Больцмана в поле внешних сил. Барометрическая формула

### Распределение Больцмана в поле внешних сил

> [!error] **Распределение Больцмана**
> Концентрация частиц идеального газа во внешнем потенциальном поле $U(\vec{r})$:
> $$n(\vec{r}) = n_0 \exp\left( -\frac{U(\vec{r})}{k_B T} \right).$$
> Полное распределение Максвелла — Больцмана в фазовом пространстве:
> $$dw = C \exp\left( -\frac{\frac{p^2}{2m} + U(\vec{r})}{k_B T} \right) d^3p \, d^3r.$$

**Вывод:**
$\square$
1. Условие гидростатического равновесия газа в силовом поле $F_z = -\frac{dU}{dz}$:
   $$dP = -n(z) dU.$$
2. Из уравнения состояния идеального газа $P = n k_B T \implies dP = k_B T dn$.
3. Приравнивая:
   $$k_B T dn = -n dU \implies \frac{dn}{n} = -\frac{dU}{k_B T}.$$
4. Интегрируя при $T = \text{const}$:
   $$n(\vec{r}) = n_0 \exp\left( -\frac{U(\vec{r})}{k_B T} \right). \blacksquare$$

### Барометрическая формула

> [!error] **Барометрическая формула**
> В однородном гравитационном поле Земли $U(h) = m g h$:
> $$P(h) = P_0 \exp\left( -\frac{m g h}{k_B T} \right) = P_0 \exp\left( -\frac{\mu g h}{R T} \right).$$
> Высота однородной атмосферы (на которой давление падает в $e$ раз):
> $$h_0 = \frac{R T}{\mu g} \approx 8{,}5 \, \text{км}.$$
> В поле центробежных сил центрифуги ($U(r) = -\frac{m \omega^2 r^2}{2}$):
> $$n(r) = n_0 \exp\left( \frac{m \omega^2 r^2}{2 k_B T} \right).$$
