# Пункт 31. Флуктуации в термодинамических системах. Основные методы вычисления флуктуаций. Влияние флуктуаций на чувствительность измерительных приборов (на примере пружинных весов и газового термометра)

### Флуктуации в термодинамических системах. Основные методы вычисления флуктуаций

> [!info] **Определение 31.1** (Флуктуации, среднее значение, дисперсия)
> **Флуктуации** — случайные спонтанные отклонения физических величин, характеризующих термодинамическую систему, от их средних равновесных значений, обусловленные хаотическим тепловым микроскопическим движением частиц.
> 
> Пусть $x$ — некоторая физическая величина (координата, давление, температура, число частиц и др.), а $\bar{x} = \langle x \rangle$ — её среднее статистическое (равновесное) значение.
> * Отклонение от среднего:
>   $$\Delta x = x - \bar{x}.$$
> * Среднее значение флуктуации тождественно равно нулю:
>   $$\langle \Delta x \rangle = \langle x - \bar{x} \rangle = \langle x \rangle - \bar{x} = 0.$$
> * **Среднеквадратичная флуктуация (дисперсия):** мера разброса величины около среднего:
>   $$\sigma_x^2 = \langle \Delta x^2 \rangle = \langle (x - \bar{x})^2 \rangle = \langle x^2 - 2x\bar{x} + \bar{x}^2 \rangle = \langle x^2 \rangle - \bar{x}^2 \ge 0.$$
>   Величина $\sigma_x = \sqrt{\langle \Delta x^2 \rangle}$ называется стандартным отклонением.
> * **Относительная среднеквадратичная флуктуация:**
>   $$\delta_x = \frac{\sigma_x}{\bar{x}} = \frac{\sqrt{\langle \Delta x^2 \rangle}}{\bar{x}}.$$

---

#### 1. Термодинамический метод Эйнштейна (через энтропию)

> [!error] **Теорема 31.1** (Распределение флуктуаций Эйнштейна — Гаусса)
> В квазистатическом приближении вероятность флуктуаций термодинамического параметра подчиняется нормальному закону (распределению Гаусса).

**Вывод:**
$\square$
1. Согласно фундаментальному статистическому постулату Больцмана, термодинамическая вероятность макросостояния связана с энтропией соотношением $S = k_B \ln W$. Следовательно, вероятность реализации состояния с заданным значением параметра $x$ пропорциональна числу отвечающих ему микросостояний:
   $$w(x) \, dx = C \exp\left( \frac{S(x)}{k_B} \right) dx,$$
   где $C$ — нормировочный множитель, $S(x)$ — полная энтропия изолированной системы при заданном значении $x$.

2. В состоянии устойчивого термодинамического равновесия ($x = x_0 = \bar{x}$) энтропия замкнутой изолированной системы достигает своего абсолютного максимума:
   $$\left. \frac{dS}{dx} \right|_{x = x_0} = 0, \quad \left. \frac{d^2S}{dx^2} \right|_{x = x_0} = -\lambda < 0 \quad (\lambda > 0).$$

3. Разложим функцию энтропии $S(x)$ в окрестности равновесного состояния $x_0$ в ряд Тейлора по малым отклонениям $\Delta x = x - x_0$:
   $$S(x) \approx S(x_0) + \left. \frac{dS}{dx} \right|_{x_0} \Delta x + \frac{1}{2} \left. \frac{d^2S}{dx^2} \right|_{x_0} (\Delta x)^2 + \mathcal{O}((\Delta x)^3) = S_0 - \frac{\lambda}{2} (\Delta x)^2.$$

4. Подставим разложение в формулу вероятности:
   $$w(x) \, dx = C \exp\left( \frac{S_0}{k_B} \right) \exp\left( -\frac{\lambda (\Delta x)^2}{2 k_B} \right) dx = A \exp\left( -\frac{\lambda (\Delta x)^2}{2 k_B} \right) dx.$$

5. Нормировочную константу $A$ найдём из условия нормировки вероятности:
   $$\int_{-\infty}^{+\infty} w(x) \, dx = 1 \implies A \int_{-\infty}^{+\infty} \exp\left( -\frac{\lambda (\Delta x)^2}{2 k_B} \right) d(\Delta x) = 1.$$
   Используя табличный интеграл Пуассона $\int_{-\infty}^{+\infty} e^{-\alpha \xi^2} d\xi = \sqrt{\frac{\pi}{\alpha}}$ при $\alpha = \frac{\lambda}{2 k_B}$:
   $$A \sqrt{\frac{2\pi k_B}{\lambda}} = 1 \implies A = \sqrt{\frac{\lambda}{2\pi k_B}}.$$

6. Вычислим средний квадрат флуктуации (дисперсию):
   $$\langle \Delta x^2 \rangle = \int_{-\infty}^{+\infty} (\Delta x)^2 w(x) \, dx = \sqrt{\frac{\lambda}{2\pi k_B}} \int_{-\infty}^{+\infty} (\Delta x)^2 \exp\left( -\frac{\lambda (\Delta x)^2}{2 k_B} \right) d(\Delta x).$$
   Используя метод дифференцирования интеграла Пуассона по параметру $\alpha$:
   $$\int_{-\infty}^{+\infty} \xi^2 e^{-\alpha \xi^2} d\xi = -\frac{d}{d\alpha} \int_{-\infty}^{+\infty} e^{-\alpha \xi^2} d\xi = -\frac{d}{d\alpha} \left( \sqrt{\pi} \alpha^{-1/2} \right) = \frac{1}{2} \sqrt{\pi} \alpha^{-3/2} = \frac{\sqrt{\pi}}{2 \alpha \sqrt{\alpha}}.$$
   Подставляя $\alpha = \frac{\lambda}{2 k_B}$:
   $$\langle \Delta x^2 \rangle = \sqrt{\frac{\alpha}{\pi}} \cdot \frac{\sqrt{\pi}}{2 \alpha \sqrt{\alpha}} = \frac{1}{2\alpha} = \frac{k_B}{\lambda}.$$

7. Учитывая определение $\lambda = -\left. \frac{d^2S}{dx^2} \right|_{x_0}$, получаем фундаментальную **формулу Эйнштейна для среднеквадратичной флуктуации**:
   $$\sigma_x^2 = \langle \Delta x^2 \rangle = -\frac{k_B}{\left. \frac{d^2S}{dx^2} \right|_{x_0}}.$$
   Плотность распределения вероятности принимает стандартный канонический вид Гаусса:
   $$w(x) = \frac{1}{\sqrt{2\pi \sigma_x^2}} \exp\left( -\frac{(x - \bar{x})^2}{2 \sigma_x^2} \right). \blacksquare$$

#### 2. Метод теоремы о равнораспределении (энергетический метод)

> [!note] **Энергетический метод для квадратичных степеней свободы**
> Если при отклонении параметра системы на $\Delta x$ потенциальная энергия возрастает квадратичным образом (гармоническое приближение):
> $$\Delta U = \frac{1}{2} \varkappa (\Delta x)^2,$$
> где $\varkappa$ — обобщённый коэффициент квазиупругой жёсткости системы, то согласно классической теореме Больцмана о равномерном распределении энергии по степеням свободы в состоянии теплового равновесия при температуре $T$ на данную квадратичную координатную степень свободы приходится средняя энергия:
> $$\left\langle \Delta U \right\rangle = \left\langle \frac{1}{2} \varkappa (\Delta x)^2 \right\rangle = \frac{1}{2} k_B T.$$
> Отсюда непосредственно следует:
> $$\langle \Delta x^2 \rangle = \frac{k_B T}{\varkappa} \implies \sigma_x = \sqrt{\frac{k_B T}{\varkappa}}.$$

### Влияние флуктуаций на чувствительность измерительных приборов (на примере пружинных весов и газового термометра)

Любой реальный измерительный прибор находится в тепловом контакте с окружающей средой при температуре $T$. Непрерывные хаотические соударения молекул среды с чувствительными элементами прибора вызывают их хаотические тепловые колебания (шумы), накладывая фундаментальное термодинамическое ограничение на предел чувствительности измерений.

---

#### 1. Чувствительность пружинных весов

> [!error] **Модель пружинных весов**
> Чувствительным элементом весов служит невесомая чашка с измеряемым грузом массы $m$, подвешенная на упругой пружине с коэффициентом жесткости $\varkappa$ в среде при температуре $T$.

$\square$
1. **Тепловые флуктуации координаты:**
   Колебания груза описываются уравнением гармонического осциллятора с потенциальной энергией $U(x) = \frac{1}{2}\varkappa x^2$. Из теоремы о равнораспределении:
   $$\left\langle \frac{\varkappa (\Delta x)^2}{2} \right\rangle = \frac{1}{2} k_B T \implies \langle \Delta x^2 \rangle = \frac{k_B T}{\varkappa}.$$
   Среднеквадратичная флуктуация положения стрелки (координаты чашки):
   $$\sigma_x = \sqrt{\langle \Delta x^2 \rangle} = \sqrt{\frac{k_B T}{\varkappa}}.$$

2. **Предел чувствительности по силе и массе:**
   При взвешивании груза дополнительное статическое смещение стрелки равно $\Delta x_{\text{изм}} = \frac{F}{\varkappa} = \frac{\Delta m \cdot g}{\varkappa}$.
   Измерение физически возможно только тогда, когда полезный сигнал превышает уровень теплового шума:
   $$\Delta x_{\text{изм}} \gtrsim \sigma_x \implies \frac{F_{\min}}{\varkappa} \sim \sqrt{\frac{k_B T}{\varkappa}}.$$
   Отсюда минимальная различимая сила:
   $$F_{\min} \sim \sqrt{\varkappa k_B T},$$
   и минимальная регистрируемая масса:
   $$\Delta m_{\min} \sim \frac{\sqrt{\varkappa k_B T}}{g}.$$

3. **Физический вывод:**
   Чтобы повысить чувствительность весов (уменьшить $\Delta m_{\min}$), необходимо:
   * Использовать максимально мягкие подвесы (уменьшать $\varkappa$);
   * Охлаждать прибор до криогенных температур (уменьшать $T$). $\blacksquare$

---

#### 2. Чувствительность газового термометра

> [!error] **Модель газового термометра**
> Газовый термометр представляет собой теплоизолированный цилиндрический сосуд объема $V_0 = S x_0$, содержащий $N$ молекул идеального газа при давлении $P_0$ и температуре $T_0$. Объем газа ограничен подвижным поршнем площади $S$, находящимся на высоте $x_0$.

$\square$
1. **Флуктуация положения поршня:**
   При малом смещении поршня $\Delta x$ объем газа изменяется на $\Delta V = S \Delta x$.
   Возникает восстанавливающая сила со стороны газа за счет изменения давления $\Delta P$:
   $$F = -S \Delta P = -S \left( \frac{\partial P}{\partial V} \right)_T \Delta V = -S^2 \left( \frac{\partial P}{\partial V} \right)_T \Delta x.$$
   Для идеального газа ($P = \frac{N k_B T}{V}$):
   $$\left( \frac{\partial P}{\partial V} \right)_T = -\frac{P_0}{V_0} = -\frac{N k_B T_0}{S^2 x_0^2}.$$
   Следовательно, возвращающая сила имеет чисто квазиупругий характер:
   $$F = -S^2 \left( -\frac{N k_B T_0}{S^2 x_0^2} \right) \Delta x = \frac{N k_B T_0}{x_0^2} \Delta x = \varkappa_{\text{эфф}} \Delta x,$$
   где эффективная жёсткость газовой пружины равна $\varkappa_{\text{эфф}} = \frac{N k_B T_0}{x_0^2}$.
   
   Используя формулу для гармонического осциллятора:
   $$\langle \Delta x^2 \rangle = \frac{k_B T_0}{\varkappa_{\text{эфф}}} = \frac{k_B T_0}{\frac{N k_B T_0}{x_0^2}} = \frac{x_0^2}{N}.$$
   Относительная среднеквадратичная флуктуация положения поршня:
   $$\frac{\sigma_x}{x_0} = \frac{\sqrt{\langle \Delta x^2 \rangle}}{x_0} = \frac{1}{\sqrt{N}}.$$

2. **Флуктуация температуры термометра:**
   Рассмотрим термометр с газом объёма $v$ (число частиц $N$) в тепловом контакте с большим термостатом объёма $V \gg v$ (полное число частиц $N_0 \gg N$) при общей температуре $T_0$.
   При возникновении тепловой флуктуации $\Delta T$ в термометре, изменение внутренней энергии термометра компенсируется термостатом:
   $$\Delta U_{\text{терм}} = N c_V \Delta T = -\Delta U_{\text{ср}}.$$
   Суммарное изменение энтропии изолированной системы «термометр + термостат»:
   $$\Delta S_{\Sigma} = \Delta S_{\text{терм}} + \Delta S_{\text{ср}} = N c_V \ln\left(1 + \frac{\Delta T}{T_0}\right) - \frac{Q_{\text{ср}}}{T_0}.$$
   Так как теплота, переданная термостату, равна $Q_{\text{ср}} = \Delta U_{\text{терм}} = N c_V \Delta T$:
   $$\Delta S_{\Sigma} = N c_V \left[ \frac{\Delta T}{T_0} - \frac{1}{2}\left(\frac{\Delta T}{T_0}\right)^2 + \dots \right] - \frac{N c_V \Delta T}{T_0} \approx -\frac{N c_V}{2} \left(\frac{\Delta T}{T_0}\right)^2.$$
   Подставляя $\Delta S_\Sigma$ в формулу вероятности Эйнштейна $w(\Delta T) \propto \exp\left(\frac{\Delta S_\Sigma}{k_B}\right)$:
   $$w(\Delta T) \propto \exp\left( -\frac{N c_V}{2 k_B T_0^2} (\Delta T)^2 \right).$$
   Сравнивая с каноническим видом Гаусса $\exp\left(-\frac{(\Delta T)^2}{2 \sigma_T^2}\right)$, получаем:
   $$\sigma_T^2 = \langle \Delta T^2 \rangle = \frac{k_B T_0^2}{N c_V}.$$
   Относительная среднеквадратичная флуктуация температуры:
   $$\frac{\sigma_T}{T_0} = \sqrt{\frac{k_B}{N c_V}} = \frac{1}{\sqrt{N (c_V / k_B)}} \propto \frac{1}{\sqrt{N}}.$$

3. **Физический вывод:**
   Относительная погрешность измерения температуры газовым термометром не может быть сделана сколь угодно малой: она принципиально ограничена величиной $\sim 1/\sqrt{N}$. Чем меньше рабочий объём (и масса) чувствительного баллончика термометра, тем сильнее тепловые флуктуации искажают результат измерения. $\blacksquare$
