# Пункт 4. Теплоёмкость. Теплоёмкости при постоянном объёме и давлении. Связь между CP и CV для идеального газа (соотношение Майера)

### Теплоёмкость. Теплоёмкости при постоянном объёме и давлении

> [!info] **Определение 4.1** (Теплоёмкость)
> **Теплоёмкость** системы — отношение подведённого количества теплоты к вызванному им изменению температуры:
> $$C = \frac{\delta Q}{dT}.$$
> * Удельная теплоёмкость: $c_{\text{уд}} = \frac{C}{m}$.
> * Молярная теплоёмкость: $c_{\text{мол}} = \frac{C}{\nu}$.

> [!note] **Теплоёмкость при постоянном объёме $C_V$**
> При $V = \text{const} \implies dV = 0 \implies \delta A = 0$:
> $$\delta Q_V = dU \implies C_V = \left(\frac{\partial U}{\partial T}\right)_V.$$
> Для 1 моля идеального газа:
> $$c_V = \frac{i}{2} R.$$

> [!note] **Теплоёмкость при постоянном давлении $C_P$**
> При $P = \text{const} \implies dP = 0$:
> $$\delta Q_P = dU + P dV = d(U + P V) = dH \implies C_P = \left(\frac{\partial H}{\partial T}\right)_P.$$

### Связь между CP и CV для идеального газа (соотношение Майера)

> [!error] **Соотношение Майера**
> Для молярных теплоёмкостей идеального газа:
> $$c_P - c_V = R.$$

**Вывод:**
$\square$
1. Из первого начала термодинамики для 1 моля:
   $$\delta Q = dU + P dV = c_V dT + P dV.$$
2. Из уравнения состояния $P V = R T$ при постоянном давлении ($P = \text{const}$):
   $$P dV = R dT.$$
3. Подставляя в выражение для $\delta Q_P$:
   $$\delta Q_P = c_V dT + R dT = (c_V + R) dT.$$
4. По определению $c_P = \frac{\delta Q_P}{dT}$:
   $$c_P = c_V + R \implies c_P - c_V = R. \blacksquare$$

> [!tip] **Показатель адиабаты**
> $$\gamma = \frac{c_P}{c_V} = \frac{c_V + R}{c_V} = 1 + \frac{2}{i}.$$
