# Пункт 5. Политропический и адиабатический процессы. Уравнение адиабаты и политропы идеального газа

### Политропический и адиабатический процессы

> [!info] **Определение 5.1** (Политропический и адиабатический процессы)
> * **Политропический процесс** — равновесный процесс, протекающий при постоянной теплоёмкости:
>   $$C = \text{const}.$$
> * **Адиабатический процесс** — частный случай политропического процесса без теплообмена с окружающей средой ($\delta Q = 0$), для которого:
>   $$C = 0.$$

### Уравнение адиабаты и политропы идеального газа

> [!error] **Уравнение политропы**
> Для идеального газа квазистатический политропический процесс описывается уравнением:
> $$P V^n = \text{const},$$
> где показатель политропы:
> $$n = \frac{C - C_P}{C - C_V}.$$

**Вывод:**
$\square$
1. Запишем первое начало для 1 моля газа:
   $$\delta Q = c dT = c_V dT + P dV \implies (c - c_V) dT = P dV.$$
2. Дифференцируя $P V = R T$:
   $$P dV + V dP = R dT = (c_P - c_V) dT \implies dT = \frac{P dV + V dP}{c_P - c_V}.$$
3. Подставляя $dT$ в первое уравнение:
   $$(c - c_V) \frac{P dV + V dP}{c_P - c_V} = P dV.$$
4. Разделив на $P V$ и сгруппировав слагаемые:
   $$\frac{dP}{P} + \frac{c - c_P}{c - c_V} \frac{dV}{V} = 0 \implies \frac{dP}{P} + n \frac{dV}{V} = 0,$$
   где $n = \frac{c - c_P}{c - c_V}$.
5. Интегрируя:
   $$\ln P + n \ln V = \text{const} \implies P V^n = \text{const}. \blacksquare$$

> [!note] **Частные случаи политропы:**
> 1. **Изотермический процесс** ($T = \text{const}$): $c = \pm \infty \implies n = 1 \implies P V = \text{const}$.
> 2. **Изобарный процесс** ($P = \text{const}$): $c = c_P \implies n = 0 \implies P = \text{const}$.
> 3. **Изохорный процесс** ($V = \text{const}$): $c = c_V \implies n = \infty \implies V = \text{const}$.
> 4. **Адиабатический процесс** ($\delta Q = 0$): $c = 0 \implies n = \frac{c_P}{c_V} = \gamma \implies P V^\gamma = \text{const}$ (**уравнение Пуассона**).
> 
> В других переменных уравнение адиабаты Пуассона:
> $$T V^{\gamma - 1} = \text{const}, \quad T^\gamma P^{1 - \gamma} = \text{const}.$$
> На $PV$-диаграмме адиабата имеет наклон $\left(\frac{\partial P}{\partial V}\right)_S = -\gamma \frac{P}{V}$, поэтому она идёт **круче**, чем изотерма $\left(\frac{\partial P}{\partial V}\right)_T = -\frac{P}{V}$.
