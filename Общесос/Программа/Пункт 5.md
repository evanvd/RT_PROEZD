# Пункт 5. Политропический и адиабатический процессы. Уравнение адиабаты и политропы идеального газа.

### Политропический и адиабатический процессы

Процессы, в которых теплоемкость является постоянной величиной, называются политропическими. В частности, политропическими являются изохорный, изобарный и адиабатический процессы.

Проведем небольшое исследование. Найдем уравнение политропического процесса для одного моля идеального газа:

$$\delta Q = C dT = C_V dT + \frac{RT}{V} dV.$$

Если считать $C = \text{const}$, то:

$$(C - C_V) \frac{dT}{T} = R \frac{dV}{V}.$$

Решая это дифференциальное уравнение, получим уравнение политропического процесса:

$$P V^n = \text{const}, \quad \text{где } n = \frac{C - C_P}{C - C_V}. \tag{3.8}$$

Число $n$ называется показателем политропы. В частности, при $C = 0$ (адиабатический процесс):

$$n = \frac{C_P}{C_V} = \gamma, \tag{3.9}$$

где $\gamma$ — показатель адиабаты.

Для изобарического процесса легко установить, что $n = 0$. Для изохорического процесса $n = \infty$. В изотермическом процессе, где $C = \infty$, значение $n = 1$.

### Уравнение адиабаты и политропы идеального газа

Для одноатомного идеального газа внутренняя энергия зависит только от температуры:

$$U(T) = N \cdot \frac{3}{2} k T = \nu \cdot \frac{3}{2} R T. \tag{2.12}$$

Калорическое уравнение состояния одноатомного идеального газа имеет вид:

$$PV = \frac{2}{3} U. \tag{2.13}$$

В общем виде для многоатомного идеального газа:

$$PV = (\gamma - 1) U, \tag{2.14}$$

где $\gamma = \frac{C_P}{C_V}$ — показатель адиабаты Пуассона.

Для адиабатического процесса ($\delta Q = 0$):

$$dU = -P dV.$$

Используя (2.14), получаем:

$$dU = \frac{P dV + V dP}{\gamma - 1} = -P dV,$$

что приводит к дифференциальному уравнению:

$$\frac{dP}{P} = -\gamma \frac{dV}{V},$$

интегрирование которого дает уравнение адиабаты Пуассона:

$$P V^\gamma = \text{const}. \tag{2.15}$$
