# Пункт 7. Уравнение Бернулли для идеального газа. Истечение идеального газа из отверстия

### Уравнение Бернулли для идеального газа

> [!error] **Уравнение Бернулли для адиабатического стационарного течения**
> Для установившегося адиабатического течения идеального газа вдоль трубки тока сумма кинетической энергии и энтальпии сохраняется:
> $$\frac{v^2}{2} + w = \text{const},$$
> где $w = u + \frac{P}{\rho}$ — удельная энтальпия единицы массы газа.
> Выражая через параметры идеального газа ($w = c_P T = \frac{\gamma}{\gamma - 1} \frac{P}{\rho}$):
> $$\frac{v^2}{2} + \frac{\gamma}{\gamma - 1} \frac{P}{\rho} = \text{const}.$$

**Вывод:**
$\square$
1. Из закона сохранения энергии для массы $m$ газа между двумя сечениями трубки тока:
   $$m \left(\frac{v_2^2}{2} - \frac{v_1^2}{2}\right) + m(u_2 - u_1) = A_{\text{внеш}}.$$
2. Внешняя работа сил давления на торцах трубки:
   $$A_{\text{внеш}} = P_1 V_1 - P_2 V_2 = m \left(\frac{P_1}{\rho_1} - \frac{P_2}{\rho_2}\right).$$
3. Приравнивая:
   $$\frac{v_1^2}{2} + u_1 + \frac{P_1}{\rho_1} = \frac{v_2^2}{2} + u_2 + \frac{P_2}{\rho_2} \implies \frac{v^2}{2} + w = \text{const}. \blacksquare$$

### Истечение идеального газа из отверстия

> [!note] **Формула Сен-Венана — Ванцеля**
> При истечении газа из большого резервуара (где начальная скорость $v_0 \approx 0$, давление $P_0$, плотность $\rho_0$) в область с давлением $P$:
> $$v = \sqrt{2(w_0 - w)} = \sqrt{\frac{2\gamma}{\gamma - 1} \frac{P_0}{\rho_0} \left[1 - \left(\frac{P}{P_0}\right)^{\frac{\gamma - 1}{\gamma}}\right]}.$$

> [!tip] **Критическая скорость и режим запирания**
> Максимальная скорость в узком сечении отверстия равна местной скорости звука $c_s$.
> Критическое отношение давлений, при котором достигается звуковая скорость:
> $$\left(\frac{P_{\text{кр}}}{P_0}\right) = \left(\frac{2}{\gamma + 1}\right)^{\frac{\gamma}{\gamma - 1}}.$$
> Для воздуха ($\gamma = 1{,}4$) отношение $\frac{P_{\text{кр}}}{P_0} \approx 0{,}528$. При дальнейшем падении внешнего давления скорость в самом отверстии не превышает скорости звука.
