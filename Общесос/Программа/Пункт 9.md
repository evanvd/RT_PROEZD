# Пункт 9. Второе начало термодинамики. Энтропия (термодинамическое определение). Равенство и неравенство Клаузиуса. Энтропия идеального газа

### Второе начало термодинамики

> [!error] **Формулировки второго начала термодинамики**
> 1. **Формулировка Клаузиуса:** Теплота не может самопроизвольно переходить от менее нагретого тела к более нагретому.
> 2. **Формулировка Томсона (Кельвина):** Невозможен круговой процесс, единственным результатом которого было бы совершение механической работы за счёт охлаждения одного теплового резервуара.
> Обе формулировки эквивалентны.

### Энтропия (термодинамическое определение)

> [!info] **Определение 9.1** (Энтропия)
> Величина $\frac{\delta Q}{T}$ называется **элементарной приведённой теплотой**.
> Для любого обратимого квазистатического процесса интеграл $\int \frac{\delta Q_{\text{обр}}}{T}$ не зависит от пути перехода и определяет изменение функции состояния — **энтропии $S$**:
> $$dS = \frac{\delta Q_{\text{обр}}}{T} \quad \iff \quad \Delta S = S_2 - S_1 = \int_{(1)}^{(2)} \frac{\delta Q_{\text{обр}}}{T}.$$

### Равенство и неравенство Клаузиуса

> [!error] **Равенство и неравенство Клаузиуса**
> Для произвольного кругового процесса интеграл приведённой теплоты удовлетворяет соотношению:
> $$\oint \frac{\delta Q}{T} \le 0,$$
> где знак равенства выполняется для **обратимых циклов** (**равенство Клаузиуса**):
> $$\oint_{\text{обр}} \frac{\delta Q}{T} = 0,$$
> а строгое неравенство имеет место для **необратимых циклов** (**неравенство Клаузиуса**):
> $$\oint_{\text{необр}} \frac{\delta Q}{T} < 0.$$

**Вывод:**
$\square$
1. Любой обратимый контур можно представить сетью изотерм и адиабат, составленной из элементарных циклов Карно.
2. Для каждого элементарного цикла Карно:
   $$\frac{\delta Q_1}{T_1} + \frac{\delta Q_2}{T_2} = 0 \implies \oint_{\text{обр}} \frac{\delta Q}{T} = 0.$$
3. Для необратимого цикла $\eta < \eta_{\text{Карно}} \implies \frac{\delta Q_1 + \delta Q_2}{\delta Q_1} < \frac{T_1 - T_2}{T_1} \implies \frac{\delta Q_1}{T_1} + \frac{\delta Q_2}{T_2} < 0 \implies \oint_{\text{необр}} \frac{\delta Q}{T} < 0. \blacksquare$

### Энтропия идеального газа

> [!note] **Формула энтропии идеального газа**
> Из первого начала термодинамики для обратимого процесса:
> $$\delta Q = dU + P dV = \nu c_V dT + \frac{\nu R T}{V} dV.$$
> Деля на $T$:
> $$dS = \nu c_V \frac{dT}{T} + \nu R \frac{dV}{V}.$$
> Интегрируя:
> $$S(T, V) = S_0 + \nu c_V \ln\frac{T}{T_0} + \nu R \ln\frac{V}{V_0}.$$
> В переменных $(T, P)$ и $(P, V)$:
> $$S(T, P) = S_0 + \nu c_P \ln\frac{T}{T_0} - \nu R \ln\frac{P}{P_0},$$
> $$S(P, V) = S_0 + \nu c_V \ln\frac{P}{P_0} + \nu c_P \ln\frac{V}{V_0}.$$
